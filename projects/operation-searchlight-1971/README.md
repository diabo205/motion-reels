# Project: Operation Searchlight 1971 Reel

## Overview
A high-retention 9:16 kinetic motion graphics documentary reel covering the military crackdown in East Pakistan launched on 25 March 1971, the midnight assault on Dhaka University, Pilkhana, and Rajarbagh, and the eventual liberation of Bangladesh.

## Specifications
- **Resolution**: 1080 x 1920 (9:16 vertical)
- **Framerate**: 60 FPS
- **Scenes**: 18 scenes
- **Audio**: `assets/audio/bgm.mp3`

## Directory Structure
- `prompt_manifest.json`: 18-scene visual manifest specifying stage styles, sky gradients, and foreground assets.
- `plates/`: Historical photographs and archival portraits (`bangladesh_flag.png`, `mujibur_rahman.jpg`, `yahya_khan.png`, `ziaur_rahman.jpg`, `searchlight_archive.jpg`, `operation_searchlight_wiki.txt`).
- `audit/`: 18 rendered audit still frames.
- `HistoricalReel.mp4`: Rendered production video.
